# Patógena S.A.

Juego de fábrica en 3D isométrico: diriges el laboratorio de una farmacéutica que provoca un apocalipsis zombi. Extraes materias primas, automatizas cadenas de máquinas y cintas, y fabricas las mutaciones del virus como productos.

- Motor: Godot 4 (GDScript)
- Plataformas: Windows (itch.io y Steam) y web
- Diseño: [documento de diseño](https://claude.ai/artifact/XVYRKWeQAvMiSUE9AbUn59) · copia en `docs/diseno.md`
- Estado: puerta 3 (pantalla objetivo)
