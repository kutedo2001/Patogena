# Referencias

Análisis de cada referencia (cámara, encuadre, luz, paleta, materiales, proporciones, densidad, interfaz, feedback) con capturas. Se completa en la puerta 3.

| Referencia | Qué tomamos |
| --- | --- |
| Satisfactory | nodos con calidad, extractores encima, hitos en un punto físico, construcción con fantasma |
| Factorio | cintas visibles, brazos, divisores, red eléctrica por postes, ratios como puzle |
| Shapez 2 | claridad de productos por forma y color, interfaz limpia |
| Timberborn | isométrico bonito, edificios con estado visible |
| Alchemy Factory | recetas de laboratorio combinables, colores vivos |
| Dyson Sphere Program | barra de construcción por categorías, panel de máquina con iconos, estadísticas |
| Palworld | ayudantes que trabajan solos en estaciones |
| Plague Inc | mapa por regiones, tres ramas de mutaciones, cura como reloj |
| Can 'Em All | correos de Dirección como hilo, sensación jugosa al procesar |

## 10 rasgos medibles (se fijan con capturas en la puerta 3)
1. La máquina más grande de la pantalla ocupa como máximo el 10 % del ancho a zoom medio.
2. El becario mide 0,9 casillas; una máquina pequeña, 1 × 1 × 1,2.
3. Cada producto se distingue por silueta a 24 px de icono.
4. Ningún texto sobre el mundo.
5. Luz de estado visible desde cualquier zoom.
6. Paleta del laboratorio: 3 neutros + 1 verde de marca; los productos saturados.
7. Sombras suaves, contraste medio.
8. HUD en los bordes, centro de la pantalla libre.
9. Cámara a 50° de inclinación, campo de visión unos 30°.
10. Densidad: a zoom medio caben unas 20 × 12 casillas.
